# Astral Cruiser

A native mod for Horizon: a huge pilotable starship with a walkable interior, lasers, coordinate dash and jump, and a portal that shows the real destination dimension live before you cross it, on foot or aboard.

Start with `/astral spawn`, then `/astral board`. Keys are in Options > Mods > Settings.

This is a native mod: the launcher compiles it into the game, without a sandbox. It adds no network access and reads no accounts or files outside the game's own data. It holds no Minecraft code or assets.

Built for Horizon commit `68ac6f647e7022b2c696e81863d7cface28c9416`, Minecraft 26.3. The bundle is in `mixins/astral_cruiser`, and the unit tests run with `cargo test`.
